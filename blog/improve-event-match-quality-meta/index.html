How to Improve Event Match Quality in Meta Events Manager

Ali RazaPerformance Marketing Specialist · 7 min read · Nov 2026

If you've set up the Conversions API, you've probably noticed a number next to each event in Events Manager called Event Match Quality. It's one of the most useful tracking health checks Meta gives you, and improving it can help your campaigns optimise better.

Quick summary

  • EMQ (0–10) shows how well your server events can be matched to Meta users.
  • Better matching means more conversions attributed and better optimisation.
  • Send more customer information parameters, hashed, with every event.
  • Prioritise Purchase, Initiate Checkout and Add to Cart.

What Event Match Quality measures

When your store sends an event like a purchase to Meta, Meta tries to connect it to a person on Facebook or Instagram. The more customer information you include, the more likely a match. EMQ is Meta's estimate of how effective that information is, shown per event in the Overview tab of Events Manager.

Why it matters

  • More attributed conversions: sales that can't be matched can't be credited to your ads.
  • Better optimisation: Meta learns who buys from matched events, which improves delivery.
  • Better audiences: retargeting and lookalikes built from events are larger and more accurate.

Customer information parameters to send

ParameterNotes
Email (em)One of the strongest identifiers. Hash with SHA-256
Phone (ph)Include country code, digits only, then hash
First and last name (fn, ln)Lowercase, hashed
City, state, zip, countryNormalised and hashed
External IDYour customer ID, consistent across events
fbp and fbcBrowser and click ID cookies, not hashed
Client IP and user agentNot hashed; required for website events sent via the server

How to improve your EMQ

  1. On Shopify, set data sharing to Maximum in the Facebook and Instagram app so the Conversions API is enabled.
  2. Capture email earlier with sign-up offers or account creation so add-to-cart and checkout events can include it.
  3. Pass fbc and fbp on server events so clicks from ads can be matched.
  4. Normalise before hashing: trim spaces, lowercase emails, and format phone numbers correctly. Badly formatted data won't match.
  5. Deduplicate browser and server events with the same event name and event ID, so you don't double count.
  6. Check Events Manager diagnostics for warnings about missing parameters or formatting.
  7. Get consent right: only send customer data in line with your privacy policy and local law.

What EMQ won't fix

A high EMQ score helps measurement and optimisation, but it won't fix weak creative or an unprofitable offer. If results are poor even with clean tracking, run through my Meta ads audit checklist. For the full server-side setup, see my Conversions API guide.

Frequently asked questions

What is Event Match Quality in Meta?

Event Match Quality (EMQ) is a score from 0 to 10 in Meta Events Manager that estimates how well the customer information sent with your server events can be matched to Meta accounts. It is shown per event for events sent through the Conversions API.

What is a good Event Match Quality score?

Meta labels scores as Poor, OK, Good or Great. Aim for Good or Great on your key events such as Purchase, Add to Cart and Initiate Checkout. Purchase events usually score higher because more customer information is available at checkout.

How do I improve Event Match Quality on Shopify?

Use Shopify's Facebook and Instagram app with maximum data sharing enabled, or a server-side setup that sends hashed email, phone, name, address and external ID along with the fbp and fbc browser identifiers, IP address and user agent.
